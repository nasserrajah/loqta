# public/models

مجلدات نماذج **GLTF** الخاصة بالمنتجات (`.gltf` + `.bin` + `textures/`).

- كل منتج في مجلد مستقل، مع الحفاظ على بنية الملفات كما كانت في الأرشيف.
- ملفات الصور **يجب** أن تبقى داخل `textures/` لأن ملف `.gltf` يشير إليها بهذا المسار.
- الربط بين المنتج والمجلد يتم في `src/data/modelRegistry.ts`.
- لا تحذف ملفات `license.txt` الخاصة بالنماذج.

أما ملفات **GLB** (ملف واحد) فمكانها `src/assets/models/<slug>.glb` وتُكتشف تلقائيًا.

التفاصيل الكاملة في `src/assets/models/README.md`.
